ИНСТРУКЦИЯ ПО ФАЙЛАМ И ЗАПУСКУ
===============================

ЧТО УЖЕ ЗАПУЩЕНО И РАБОТАЕТ (не перезапускать без нужды):
  backend  → http://localhost:8000/api/docs (Swagger)   — docker compose

  postgres → localhost:5432 (docker), redis — запущен (docker)

ЗАПУСК С НУЛЯ
-------------

  Один файл:  start.cmd  (двойной клик)
    - сам поднимет Docker Desktop, если он не запущен;
    - docker compose up -d: postgres + redis + api + frontend;
    - подождёт отклика и откроет http://localhost:3000;
    - первый запуск фронта ставит зависимости в контейнере (2-5 минут).

  stop.cmd   — остановить (всё закэшировано, следующий старт быстрый)
  reset.cmd  — полный сброс демо-данных (состояние как на скриншотах)

  Вручную:
    docker compose up -d --build              # postgres + redis + api + frontend
    # стенд :3000, swagger :8000/api/docs

  Проверка: cd backend && python scripts\e2e_smoke.py   # 36 проверок, нужен живой api


РЕЖИМЫ ДЛЯ ПРОВЕРКИ
-------------------

  Лендинг: демо-CAT (3 задания, без регистрации; выбор специальности и языка
           заданий) — адаптив и θ на глазах
  Кандидат:  регистрация (любой email, код покажется на экране) → профиль →
             ФСП ID: FSP-2026-0001 (есть история) или FSP-9999-999 (нет истории) →
             тестирование (8 специализаций) → категория в шапке →

             приглашения (принять/отклонить) → вакансии/отклики → задачи

             воронка найма, топ категории → приглашение (зарплата от-до, свой тест) →
             свои тесты (автосборка через интернет ~10 сек, удалить/добавить
             вопросы, посмотреть образцы с верными ответами → галочка → опубликовать) → вакансии → статусы приглашений
